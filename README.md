# ExtraCredit

ExtraCredit is a secondhand marketplace for students worldwide. Students list items, look for items near campus, and arrange local pickup through purchase inquiries. Each listing carries its own price currency.

This repository is the hand-coding plan. Start with the [ticket index](tickets/README.md), then use the [architecture and API contracts](docs/architecture.md) and the [database and view contracts](docs/database.md) alongside your issue. The [course coverage checklist](docs/course-coverage.md) connects the build to the report and demo.

## Start here

1. Everybody tries the independent practice tickets 001–006. The exercises work in a personal scratch folder or practice repo. A teammate can help you through your first pull request.
2. For shared work, pick a ticket whose prerequisites are complete. Comment to claim it, make a branch from current `main`, and concentrate on the files named in the issue. Ticket order is a suggested route through the project. Prerequisites tell you what actually needs to land first.
3. Write the change by hand. Use the learning resources and the tutoring prompt for concepts and hints. Run every acceptance check. Paste the review prompt, the issue's checks, and your relevant sanitized diff or draft into your AI reviewer.
4. Open a pull request with the ticket link, what you tried, actual results, and what changed after review. Have a teammate review your work and rerun an important check before merging. Close the issue when its work is complete. Record who contributed and what they did for the final contribution matrix.

Use made-up campus names, email addresses, listing examples, and photos you can share. Keep the original course PDFs, student numbers, credentials, local configuration, uploads, and private data off this public repository. See ticket 010 for the team's first ignore-file and configuration work.
