# ExtraCredit

ExtraCredit is a secondhand marketplace for Ontario Tech University students. Confirm your Ontario Tech student email to browse listings, post items, and arrange pickup at North Oshawa or Downtown Oshawa. Admins can open ten MySQL reports and download CSV or PDF files. Students can save the Oshawa pickup forecast. [Student email](https://ontariotechu.ca/current-students/index.php) · [Campus locations](https://registrar.ontariotechu.ca/registration/campus-locations.php)

## Run locally

Use Python 3.12 or 3.13 and MySQL 8.4 LTS. [Python downloads](https://www.python.org/downloads/) · [MySQL downloads](https://dev.mysql.com/downloads/mysql/8.4.html)

On Linux or macOS:

```sh
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
cp .env.example .env
```

On Windows PowerShell:

```powershell
py -3.12 -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
Copy-Item .env.example .env
```

Start MySQL. If you already have MySQL, connect as a local administrator and create a database and app account. Replace the example password with a local password.

```sql
CREATE DATABASE IF NOT EXISTS extra_credit CHARACTER SET utf8mb4;
CREATE USER 'extra_credit_app'@'127.0.0.1' IDENTIFIED BY 'replace-with-your-local-password';
GRANT ALL PRIVILEGES ON extra_credit.* TO 'extra_credit_app'@'127.0.0.1';
```

With Docker, another option is to start your own local demo database. Use the loopback port to keep it on your computer. Edit the example password before running the command.

```sh
docker run -d --name extra-credit-mysql -p 127.0.0.1:3307:3306 -e MYSQL_RANDOM_ROOT_PASSWORD=yes -e MYSQL_DATABASE=extra_credit -e MYSQL_USER=extra_credit_app -e MYSQL_PASSWORD=replace-with-your-local-password mysql:8.4
```

In `.env`, set `DB_PASSWORD` to the app account password. Use `DB_PORT=3307` for the Docker command above. For a Unix socket connection, set `DB_SOCKET` and create the MySQL account and grants for `'extra_credit_app'@'localhost'`. Set `SECRET_KEY` to a value generated by `python -c "import secrets; print(secrets.token_hex(32))"`. With a blank key, the app generates a temporary one and signs users out on restart.

```sh
python -m flask --app extracredit init-db
python -m flask --app extracredit seed-demo
python -m flask --app extracredit run
```

`seed-demo` works on an empty local schema and asks you to choose a password for the fictional accounts. It inserts at least six rows per table, including six labeled sample forecasts. With `DEMO_MODE=true` in your local `.env`, open `http://127.0.0.1:5000/` and sign in to browse. Use `alex@example.com` as a seller, `priya@example.com` as a buyer, and `admin@example.com` for reports and category management. Each uses the password you chose. Keep `.env`, uploads, real contact information, and passwords local.

To try registration on your own machine, use a fictional `@ontariotechu.net` address and open the link from the newest `instance/verification/student-*.txt` file. Demo mode writes confirmation links locally. Use the ExtraCredit password you chose when you registered.

For real confirmation emails, set `DEMO_MODE=false`, `PUBLIC_URL` to the app’s HTTPS URL, `COOKIE_SECURE=true`, and the `SMTP_*` settings for your STARTTLS mail service. The app checks access to the mailbox. Students also confirm current enrollment by self-attestation. For an older demo, use a fresh `extra_credit_ontario_tech` database and the new seed so earlier sample listings and accounts are preserved separately.

If you get a 503, verify that MySQL is ready and that the same host, port or socket, account, and database work from your SQL client. If the demo seed says the database is populated, use your existing data or start a fresh local demo schema. Use a separate local server for test credentials. Open-Meteo requires internet access. Catalog and report charts work locally with the bundled Chart.js asset.

## Tests

```sh
python -m pip install -r requirements-dev.txt
python -m pytest -q
```

The plain command runs tests that do not need a working database. To run integration tests, provide the temporary MySQL connection in `TEST_DB_HOST`, `TEST_DB_PORT`, `TEST_DB_USER`, `TEST_DB_PASSWORD`, or `TEST_DB_SOCKET`, then set `RUN_DB_TESTS=1` and run the same command. Use a test account that can create and drop databases on an isolated MySQL server. Each integration test creates and removes its own randomly named `extra_credit_test_…` schema.

The [Linux install check](https://github.com/ifnidbi/Extra-Credit/actions/workflows/linux-check.yml) runs the setup on Ubuntu with MySQL 8.4 and checks the seeded catalog and database tests.
