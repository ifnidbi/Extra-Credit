# 002 · Write a tiny Python price label

**Estimate** 30 minutes · **Stage** Practice  
**Prerequisites** None. Start any time.

## In brief

Practice a variable, a function, and two simple examples before working on the app.

## Technical steps

1. In a scratch `price_label.py`, create variables `item_name` and `price`. Define `format_label(item_name, price)` to return readable text and print its result for two different items.
2. Change one input and observe where the output changes. Explain parameter versus return value in one sentence.

## In first-time-coder language

1. In a practice file, store the name of a thing and its price. Give a little machine those two details and have it hand back a label.
2. Try two different objects. Change one price and see which label changes. Tell a teammate what went into the machine and what came out.
