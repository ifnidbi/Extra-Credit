# 093 · Rehearse and defend the demo

**Estimate** 45 minutes · **Stage** Delivery  
**Prerequisites** #85, #87, #91, #92

## In brief

Practice handing off between teammates and responding to questions.

## Technical steps

1. Run the demo on seeded local data from fresh start using timed speaker handoffs. Practice guest/student/admin, buying and selling, report pages, chart, downloads, and a live weather read/save. Prepare pre-captured results in case an external outage occurs, clearly labeled as captured.
2. Practice explaining ANY, the MySQL full outer join equivalent, one state transaction and one performance tradeoff. Record time and blockers.

## In first-time-coder language

1. Pretend the class is watching. Start the app, hand off between the three of you, and talk through what people can see and what got saved.
2. Ask each other hard questions about the database. Have a clearly labeled screenshot ready if the weather service goes down.

## Check your work

- [ ] A timed run stays within 5–7 minutes and covers the marked demo steps. Each member explains at least one design choice.
- [ ] Backup evidence and question responses are available, and any remaining blocker is recorded and owned.
