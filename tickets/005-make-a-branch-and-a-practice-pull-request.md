# 005 · Make a branch and a practice pull request

**Estimate** 30 minutes · **Stage** Practice  
**Prerequisites** None. Start any time.

## In brief

Practice the Git workflow using one harmless text file.

## Technical steps

1. In a personal practice repository, create a branch, add a note, make a commit, push the branch, and open a pull request.
2. Read the changed-files view and write a short summary of exactly what the branch changes. If another teammate is available, ask for practice feedback.

## In first-time-coder language

1. Make your own small copy of a practice project, add a one-line note, and save a named snapshot.
2. Put that snapshot on GitHub and ask it to show what would change. Read the difference and describe it.

## Check your work

- [ ] The pull request shows just the note you intended to change.
- [ ] You can point out the branch, the commit, and the pull request.

Read or watch the relevant part, then try a small practice example. Use the tutoring prompt when you want a hint or an explanation of an error.
