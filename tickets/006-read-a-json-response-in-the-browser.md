# 006 · Read a JSON response in the browser

**Estimate** 30 minutes · **Stage** Practice  
**Prerequisites** None. Start any time.

## In brief

Learn to tell a browser request from the response it receives.

## Technical steps

1. Open the MDN Fetch example and find a response in the Network panel. Record one HTTP method, status, and example JSON field.
2. In scratch `example.json`, describe an imaginary item with an object containing a title, price, and available flag. Recognize strings, numbers, and booleans.

## In first-time-coder language

1. Watch a web page ask for something. In the browser toolbox find what it asked for and whether the request worked.
2. Write a short machine-readable note for a pretend item, including its name, price, and whether it is available.

## Check your work

- [ ] Your notes show a method, status and response field from an actual example.
- [ ] A JSON viewer or validator parses your three-field example.

Read or watch the relevant part, then try a small practice example. Use the tutoring prompt when you want a hint or an explanation of an error.
