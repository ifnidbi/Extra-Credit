# 003 · Build a one-page practice item card

**Estimate** 30 minutes · **Stage** Practice  
**Prerequisites** None. Start any time.

## In brief

Try HTML tags and form labels on a fictional listing.

## Technical steps

1. In scratch `item.html`, add a heading, short item summary, and form with a label associated to an input by matching `for` and `id`, plus a button.
2. Open the file in a browser and inspect the input in developer tools. Try moving through the controls using Tab.

## In first-time-coder language

1. Make a little page for an imaginary used book. Give it a title, a short description, a labeled box, and a button.
2. Open the file. Press Tab to move between controls and see where the input comes from in the page.

## Check your work

- [ ] The page opens from disk and the heading is visible.
- [ ] Clicking the label focuses the input, and Tab reaches the button.
