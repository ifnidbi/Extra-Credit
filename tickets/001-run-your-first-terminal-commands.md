# 001 · Run your first terminal commands

**Estimate** 15 minutes · **Stage** Practice  
**Prerequisites** None. Start any time.

## In brief

Find your way around a practice folder from a terminal.

## Technical steps

1. Open the Terminal in VS Code or your system terminal. Identify the shell and current working directory.
2. Create a personal scratch directory named `extra-credit-practice`, navigate into it, list its contents, and check your Python interpreter version.
3. Write a two-line personal note naming a command and what it does.

## In first-time-coder language

1. Open the window where you type commands. Ask it which folder you are in.
2. Make a practice folder, go inside, and ask what is there. Ask Python for its version.
3. Write down what one command did so you can show a teammate.
