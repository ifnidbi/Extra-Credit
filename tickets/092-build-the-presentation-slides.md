# 092 · Build the presentation slides

**Estimate** 60 minutes · **Stage** Delivery  
**Prerequisites** #8, #85, #88

## In brief

Give a 5–7 minute course presentation with a clear demo path.

## Technical steps

1. Create PowerPoint slides on problem, data design, walkthrough, ten-view reporting and one measurable result. Show external REST/JSON and the two related DB operations. Divide speaking roles and build a timing budget between 5 and 7 minutes.
2. Keep slides readable with short labels and screenshots. Add optional backup details for the two minutes of questions.

## In first-time-coder language

1. Make a few slides that explain the problem and show the app. Give each person something useful to say and put the best database evidence where the audience can read it.
2. Plan how long each person talks and keep a couple of extra explanations ready for questions.

## Check your work

- [ ] Slide order supports a timed 5–7 minute presentation with each member contributing.
- [ ] Slides include schema, demo path, a view/metric and the weather data flow with readable screenshots.
